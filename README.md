# design-kata

設計の良い例・悪い例をPHPで書いて、実際に動かして確かめる練習リポジトリ。

## 何をしているか

『良いコードと悪いコードで学ぶ設計入門 ―保守しやすい 成長し続けるコードの書き方』
(仙塲大也 / 技術評論社) を読みながら、本文中のJavaのサンプルをPHPで書き直して動かしている。

読むだけだと「悪い例がなぜ悪いのか」が腹落ちしないので、bad / good の両方を実際に実行して、
エラーメッセージや挙動の差分まで見ることを目的にしている。

Javaで書かれた設計の話をPHPに翻訳する過程で言語機能の差が炙り出されるのも狙いのひとつ。
たとえば以下のようなことが、実際に書いてみて初めて分かった。

- Javaの `final` フィールドに相当するのは PHP では `readonly`。PHPの `final` は継承制御専用でプロパティには付かない
- Javaの `final` 引数・ローカル変数に相当するものは PHP に存在しない
- `private readonly` なプロパティを外から書き換えると、`readonly` ではなく `private` のエラーが先に出る

## 構成

章ごとにディレクトリを切る。

```
chapter-03/
├── bad/
│   └── Money.php
└── good/
    └── Money.php
```

## 実行

PHP 8.5 で動作確認している。

```bash
php chapter-03/good/Money.php     # 実行する
php -l chapter-03/good/Money.php  # 構文チェックのみ(実行しない)
```

## 注意

本のコードをそのまま転載したものではなく、内容を踏まえてPHPで書き直したもの。
